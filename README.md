# 社内ITサポートチャットボット

PythonとStreamlitを使用して制作した、社内IT問い合わせ対応を支援するWebアプリケーションです。

※本アプリは学習・ポートフォリオ用の試作品です。FAQとPDFマニュアルはすべて架空の内容です。

## Webアプリを試す

[チャットボットを開く](https://mikangrapefruit-it-support.streamlit.app/)

## 1. 開発目的

社内業務では、利用頻度の低い手順やマニュアルを探す際に時間がかかることがあります。

そこで、利用者が必要な情報に素早くアクセスできる仕組みを目指し、社内ITサポートチャットボットを制作しました。

## 2. 主な機能

- カテゴリ別のFAQ検索
- 自然文入力による類似FAQ検索
- 事前登録されたPDFマニュアルの本文検索
- FAQの回答と関連するPDF抜粋の表示
- 回答の参照元表示
- PDFの文書名・ページ番号表示
- 該当する情報がない場合の担当者案内
- CSVファイルによるFAQ管理

現在、架空の社内IT問い合わせFAQを100件、デモ用PDFマニュアルを1件（3ページ）登録しています。

## 3. 使用技術

- Python
- Streamlit
- pandas
- scikit-learn
- pypdf
- CSV

## 4. 自然文検索の仕組み

scikit-learnのTF-IDFとコサイン類似度を使用しています。

入力された文章と登録済みFAQの文字の組み合わせを比較し、最も類似度の高いFAQを検索します。さらに、事前登録済みPDFから抽出した文章も検索し、近い内容の抜粋を表示します。

類似度が0.30以上の場合に回答を表示します。

※類似度の基準値は暫定設定です。文章の意味を理解する生成AIではないため、表現によっては適切なFAQを検索できない場合があります。

PDF検索でも日本語文字の2〜3文字の組み合わせを使います。検索結果は文章の抜粋であり、生成AIが作った回答ではありません。

## 5. 工夫した点

### 利用者の操作性
カテゴリ選択と自由入力の2種類の検索方法を用意しました。

### 保守・運用のしやすさ
FAQデータをCSVファイルで管理し、Pythonのコードを変更せずに質問や回答を追加できる構成にしました。

PDFを `manuals/` フォルダに追加すると、コードを変更せずに検索対象へ加えられます。

### 回答の信頼性
回答に参照元を表示し、該当するFAQが見つからない場合は担当者への問い合わせを案内します。

PDF検索結果には元のファイル名とページ番号を明示し、内容を確認できるようにしました。

## 6. PDFマニュアルの登録方法

1. GitHubリポジトリの `manuals/` にPDFファイルを追加します。
2. 変更を `main` ブランチへコミットします。
3. Streamlitの再デプロイ後、キーワード検索で内容を検索できます。

文字が選択できるPDFに対応しています。スキャン画像のみのPDFは文字を抽出できないため、OCR機能の追加が必要です。パスワード付きPDFは未対応です。

**重要:** このリポジトリとWebアプリは公開されています。実際の社内機密資料、個人情報、非公開マニュアルを登録しないでください。

## 7. 起動方法（Windows）

Pythonをインストールした環境で、以下のコマンドを実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```
